回旋仪导航 · 陀螺的惯性定向

初始时 θ̇ = 0, φ̇ = 0，角速度只沿对称轴：ω = (0, 0, ω₃)。 无外力矩时 dL/dt = 0，而 L = I₃ω₃e₃，所以 e₃、|ω|、|L| 在惯性空间中都保持不变 —— 这正是陀螺能作为航向基准的原因。载体转向或俯仰时，陀螺轴仍保持惯性方向。

要点：理想模型无外力矩、无初始扰动，θ̇ = φ̇ = 0，因此 L 在惯性系严格守恒。 载体可以转向和俯仰，陀螺轴始终锁定惯性方向；载体相对陀螺的转角就是航向/姿态读数。 真实陀螺仍有轴承摩擦、质量不平衡、地球自转（约 15°/h）等误差源，导航级陀螺需要精密支承与补偿。
